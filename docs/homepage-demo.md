# 首页五秒快览

首页使用 `Hero.astro` 中的 `DictationDemo featured`：导航下先显示录音胶囊、
口述字幕，再显示简化聊天窗口。标题和下载入口位于演示下方。独立对照页
`/preview/dictation/` 复用同一组件。

`src/data/dictation-demo.json` 分开配置真实动画时长（`durationMs: 5000`）和
示意口述时长（`sourceDurationMs: 20000`）。页面明确标记“演示示例 · 4× 快览”，
不是对实际识别或文字整理耗时的承诺。所有字幕和结果都是预设，不申请麦克风权限，
不调用 ASR、大语言模型或发送消息。

时间线：0–0.2 秒准备，0.2–2.7 秒展示口述，2.7–3.4 秒整理，3.4 秒填入结果，
5 秒完成后无限期保留结果、不循环。空闲状态使用录音阶段的静态海报；不自动播放。
点击播放、暂停、继续或重播均复用单个可取消动画时钟。切换页面自动暂停，卸载组件
清理帧回调和事件。减少动态效果时使用静态波形和完整口述字幕。

`scripts/dictation-demo.test.mjs` 覆盖五秒边界、示意时钟、阶段、结果保留、暂停、
重播、卸载和迟到回调；构建检查还覆盖两个下载来源的准确名称、链接及顺序。
