# 首页八秒循环快览

首页使用 `Hero.astro` 中的 `DictationDemo featured`：导航下先显示录音胶囊、
口述字幕，再显示简化聊天窗口。标题和下载入口位于演示下方。独立对照页
`/preview/dictation/` 复用同一组件。

`src/data/dictation-demo.json` 分开配置真实动画时长（`durationMs: 8000`）和
示意口述时长（`sourceDurationMs: 20000`）。页面明确标记“演示示例 · 2.5× 快览”，
不是对实际识别或文字整理耗时的承诺。所有字幕和结果都是预设，不申请麦克风权限，
不调用 ASR、大语言模型或发送消息。

时间线：0–0.32 秒准备，0.32–4.32 秒展示口述，4.32–5.44 秒整理，5.44 秒填入结果，
停留约 2.6 秒供阅读，8 秒时开始下一轮。首页进入即自动播放，使用同一个帧时钟循环，
不会堆积定时器。切到后台或离开页面时暂停，返回后继续；手动暂停不会被自动恢复。
卸载组件清理帧回调和事件。自动循环不重复触发读屏播报。

减少动态效果模式不自动播放、不循环，使用静态海报、稳定波形与完整口述字幕；
仍可手动播放一轮。恢复正常动效时遵守此前的手动暂停选择。

`scripts/dictation-demo.test.mjs` 覆盖八秒边界、跨轮暂停、动态关闭循环、自动播放策略、
示意时钟、阶段、结果停留、重播、卸载和迟到回调；构建检查还覆盖下载入口。
